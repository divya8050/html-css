Welcome to Day 2!

Today, we're building a foundational web page using semantic HTML5 elements and applying initial CSS3 styles. This helps structure our content logically and prepare for more advanced layouts.

Understanding Semantic HTML

Semantic HTML means using HTML tags that accurately describe the purpose of the content they contain. For example, using <header> for introductory content, <nav> for navigation links, <main> for the dominant content, <section> for thematic grouping, <article> for independent content, and <footer> for concluding information.

This not only makes our code cleaner and easier to read for other developers, but it also improves accessibility for screen readers and helps search engines understand the content better.

Why Modern CSS?

  • Flexbox: For efficient one-dimensional layouts (rows or columns).
  • CSS Variables: For managing consistent styles across the site easily.
  • Clean Class Names: Using BEM or natural kebab-case for maintainability.
