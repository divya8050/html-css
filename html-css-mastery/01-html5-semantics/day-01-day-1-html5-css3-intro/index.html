HTML5 & CSS3 Basics

Today marks the beginning of our 180-day journey to master frontend design. We're starting with the foundational blocks: HTML5 for structure and CSS3 for styling.

HTML (HyperText Markup Language) provides the content and structure for web pages. It uses semantic tags to give meaning to different parts of a document.

Key HTML Elements Learned Today:

  • <html>: The root element of an HTML page.
  • <head>: Contains meta-information about the HTML document.
  • <body>: Contains all the visible content of the page.
  • <header>: Represents introductory content or a set of navigational links.
  • <main>: Represents the dominant content of the <body>.
  • <section>: A standalone section of content.
  • <h1>-<h6>: Heading elements.
  • <p>: Paragraph element.
  • <ul> & <li>: Unordered list and list item.
